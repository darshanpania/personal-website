This file exists so Astro's content collection for local posts has at least one entry, which suppresses an empty-collection warning during build. It is filtered out of the blog index by `draft: true`.

Delete this file once you publish a real local post.

## Frontmatter fields

```yaml
title: "Your post title"
date: 2026-04-01
category: tech | fiction | non-fiction
description: "Optional one-liner shown in metadata."
draft: false
```

The post will render at `/blog/<filename>` once `draft: false`.
