The app release cadence as we know it — biweekly, gated, with a long tail of stragglers — was a workaround for a constraint that no longer exists.

When app stores were the only delivery channel, you batched everything into a release because shipping was expensive. Remote configs invert that: shipping is cheap, *deciding* is expensive.

## A feature flag is a release

The smallest unit of "release" is no longer a binary. It's a configuration change scoped to a cohort. That changes who owns the release decision, when it happens, and how it gets rolled back.
