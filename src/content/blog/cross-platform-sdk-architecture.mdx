There is no clean win in cross-platform SDKs. Every choice is a tradeoff between binary size, consistency, and team capability.

## The decision matrix that actually worked

For each new platform we onboarded, we asked four questions:

- What's the customer's native developer count?
- How important is binary size?
- How frequently does the platform's API surface churn?
- Do we have a team member who genuinely owns this platform?

The last one matters more than the first three combined. Code without an owner rots.
